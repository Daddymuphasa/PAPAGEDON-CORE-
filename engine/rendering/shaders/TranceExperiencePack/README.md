# TRANCE Experience Pack

Twenty original standalone GLSL fragment shaders for TRANCE, an outdoor R&B cocktail event with classy slow music, night air, moonlit atmosphere and dreamy luxury.

The pack avoids reusing the older rave/aggressive shader language. Its motion vocabulary is slower and softer: velvet folds, champagne glints, glass caustics, garden mist, satin water, rose-gold moon arcs, candle diffusion, lounge constellations and slow-blooming halos.

Use `PAPAGEDON_SHADER_DIR=engine/rendering/shaders/TranceExperiencePack` to load only this pack, or leave the default scanner to include it with the rest of the shader library.
